# nine-pyxels

(Retro Platformer with 9 Levels using Python Pyxel.)

Welcome! You are the white rectangle. Try to get through all nine levels (starting at level 1) as quickly as possible. The grey and red blocks kill you and the green blocks are the exit that you must reach! It is challenging so you can practice by starting at a later level (meaning the speed run timer would not work). The yellow and orange blocks help you jump higher! There is a yellow block with a cross, representing a key that you must collect. You can also phase through walls by using an orange or yellow block to elevate you. Additionally, there is lag in the game that is intentional. You might need it to pass levels! There are enemies that follow you. If they touch you, you die! Flashing objects kill you. Also, some blue blocks reduce gravity! Sometimes, paths may require hard timing and the ability to read the level well and use weird gimmicks and lag in the game. Good luck (the game is not easy)!
